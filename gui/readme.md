# GUI de DUINO Transfer

## Requirimientos

- Python v3.14+
- Tkinter
- Arduino UNO
- Arduino Nano

## Instalacion

1. Crear ambiente de entorno virtual
```bash
python -m venv .venv
```

2. Activar el entorno
```bash
# Windows
.venv\Scripts\activate

# MacOS / Linux
source .venv/Scripts/activate
```

3. Instalar dependencias
```bash
pip install requirements.txt
```
